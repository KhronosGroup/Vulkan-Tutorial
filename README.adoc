== About

This repository hosts the contents of the link:https://docs.vulkan.org/tutorial/latest[Khronos Vulkan Tutorial].
The tutorial is part of the link:https://github.com/KhronosGroup/Vulkan-Site[Vulkan Documentation Project].
Start with the online tutorial if you want to learn Vulkan.

The repository hosts several tutorials:

* The primary **Khronos Vulkan Tutorial** updates the traditional link:https://vulkan-tutorial.com/[Vulkan Tutorial by Alexander Overvoorde] to use modern Vulkan features and practices.
See link:en/00_Introduction.adoc[the introduction] for a quick start.
* A set of tutorials on advanced Vulkan topics, which you can follow once you have completed the primary tutorial.
They are listed in the link:en/00_Introduction.adoc#_advanced_topics[advanced topics section] of the introduction.

== Project Structure

* `en/` - the tutorial content in English.
** `en/00_Introduction.adoc` to `en/17_Multithreading.adoc`, together with the numbered subdirectories, make up the primary Khronos Vulkan Tutorial.
** `en/Building_a_Simple_Engine/`, `en/Advanced_glTF/`, `en/Advanced_Vulkan_Compute/`, `en/Synchronization/`, `en/ML_Inference/`, `en/OpenXR_Vulkan_Spatial_Computing/` and `en/AI_Assisted_Vulkan/` contain the tutorials on advanced topics.
** `en/courses/` contains the SIGGRAPH courses.
* `attachments/` - code examples, shaders, and resources used by the tutorials.
* `images/` - illustrations, diagrams, and screenshots.
* `scripts/` - utility scripts, including dependency installation scripts.
* `antora/` - the configuration for the link:https://antora.org/[Antora] documentation system the site is built with.

== Building the Code Examples

The code for the primary tutorial lives in `attachments/`.
The tutorial's link:en/02_Development_environment.adoc[development environment chapter] explains how to set up the dependencies, and `scripts/` contains scripts that install them on Linux and Windows.
Some of the advanced tutorials have additional requirements, which are described in their own chapters.

== Previewing Changes to the Tutorial

The tutorial is written in AsciiDoc and rendered with Antora, so some things that look broken in GitHub's preview, such as missing images or cross-references, are expected.
See link:CONTRIBUTING.adoc[CONTRIBUTING.adoc] for how to preview AsciiDoc in your editor.

To build the documentation the same way CI does, follow the steps in link:.github/workflows/build-antora-doc.yml[`build-antora-doc.yml`]:
build the Khronos Antora UI bundle from link:https://github.com/KhronosGroup/antora-ui-khronos[antora-ui-khronos], copy `ui-bundle.zip` to the repository root, run `make` in `antora/`, and then run `npx antora antora-ci-playbook.yml` from the repository root.
